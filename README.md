# Лавка — каталог продуктов

Учебный каталог из 10 продуктов питания: поиск, фильтры по категориям, сортировка и итоги склада. Адаптивная страница без зависимостей и сборки.

Сайт: https://f0reste.github.io/groceries-database/

`groceries.sql` — отдельный пример для MySQL с созданием базы и таблицы, 10 записями, вычисляемой суммой и закомментированными примерами удаления.

Сайт показывает встроенный набор данных. Чтобы изменить его, отредактируйте массив `products` в `index.html`. Подключение к серверной базе данных не требуется.

GitHub Pages: ветка `main`, папка `/ (root)`.
